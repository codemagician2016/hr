# drifthr — Brand Asset Kit

Effortless HR & payroll. The mark is three flowing "drift" strokes with a leading
particle — air currents that read as smooth, hands-off motion.

## Files

### /svg  (scalable — use these on the web wherever possible)
- drifthr-logo-primary.svg — horizontal lockup, full colour (default logo)
- drifthr-logo-stacked.svg — icon-over-wordmark, full colour
- drifthr-logo-white.svg — all-white lockup, for dark/photo backgrounds
- drifthr-logo-ink.svg — single-colour ink lockup, for one-colour print
- drifthr-icon.svg — app-icon tile (gradient), the square symbol
- drifthr-icon-white.svg / drifthr-icon-ink.svg — bare symbol, one colour

### /png  (raster exports)
- drifthr-icon-512.png / -1024.png — app stores, large icons
- drifthr-logo-primary.png / -stacked.png / -ink.png / -white.png — 1600px wide
- drifthr-social-1200x630.png — Open Graph / link-preview image

### /favicon
- favicon.svg, favicon.ico, favicon-16/32/48/64.png, apple-touch-icon.png
- favicon-snippet.html — paste the tags into your site <head>

Mark gradient: Teal #16B6A6 → Blue #3B6FE3 (top-left to bottom-right).

## Typeface
Wordmark is set in Manrope ExtraBold (open-source, SIL OFL) and outlined to
paths in these files, so nothing needs the font installed to render correctly.
Pair body/UI text with Manrope (Regular/Medium) for a consistent system.

## Clear space & minimum size
- Keep clear space around the logo of at least the height of the "d".
- Minimum width: 90px (primary), 28px (icon). Below that, use the icon only.

## White-labeling
For partner-branded deployments, use drifthr-icon-white.svg / -ink.svg or the
single-colour lockup and recolour by swapping the gradient stops or the single
fill — every asset is editable vector.

## Don'ts
Don't stretch, rotate, recolour outside the palette, add shadows/outlines,
or place the colour logo on low-contrast backgrounds (use white/ink versions).
